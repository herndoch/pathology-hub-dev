# ChatGPT prompts for Heme SH Anki builder zips

These `.txt` files are the paste prompt for each series.

- `CHATGPT_PROMPT_UNIVERSAL.txt` — works with any series zip
- `CHATGPT_PROMPT_<slug>.txt` — series-specific (includes BM Intro survey caveat)

They are **not** inside the raw GCS lecture packages (`Heme_SH_*_package.zip`).
They are written into Colab-built `series_*_chatGPT_upload.zip` bundles, and also live here on GitHub for copy-paste.
