## Concrete SQL examples to include

Include SQLite snippets like these, adapted to the actual tables discovered:

List tables:

```sql
SELECT name, type
FROM sqlite_master
WHERE type IN ('table', 'view')
ORDER BY type, name;
```

List columns:

```sql
PRAGMA table_info(main_table_name);
```

Integrity checks:

```sql
PRAGMA integrity_check;
PRAGMA foreign_key_check;
```

Find blank/null source pointers:

```sql
SELECT COUNT(*) AS missing_source_pointer
FROM records
WHERE COALESCE(TRIM(source_gcs_uri), '') = ''
  AND COALESCE(TRIM(source_json_url), '') = ''
  AND COALESCE(TRIM(source_page_url), '') = ''
  AND COALESCE(TRIM(video_url), '') = '';
```

Find malformed GCS URIs:

```sql
SELECT id, source_gcs_uri
FROM records
WHERE source_gcs_uri IS NOT NULL
  AND TRIM(source_gcs_uri) <> ''
  AND source_gcs_uri NOT LIKE 'gs://pathology_hub/%'
  AND source_gcs_uri NOT LIKE 'gs://pathology-hub-0/%'
LIMIT 100;
```

Find public storage URLs without corresponding GCS URI:

```sql
SELECT id, source_json_url, source_page_url, page_image_url, video_url
FROM records
WHERE (
    source_json_url LIKE 'https://storage.googleapis.com/%'
    OR source_page_url LIKE 'https://storage.googleapis.com/%'
    OR page_image_url LIKE 'https://storage.googleapis.com/%'
    OR video_url LIKE 'https://storage.googleapis.com/%'
  )
  AND COALESCE(TRIM(source_gcs_uri), '') = ''
LIMIT 100;
```

Find JSON-looking flattened fields:

```sql
SELECT id, tags
FROM records
WHERE TRIM(tags) LIKE '[%'
   OR TRIM(tags) LIKE '{%'
LIMIT 100;
```

Find comma-delimited tag fields:

```sql
SELECT id, tags
FROM records
WHERE tags LIKE '%,%'
LIMIT 100;
```

Find duplicate semantic rows:

```sql
SELECT curriculum_unit_id, tag, source_type, COUNT(*) AS n
FROM records
GROUP BY curriculum_unit_id, tag, source_type
HAVING COUNT(*) > 1
ORDER BY n DESC
LIMIT 100;
```

Find placeholder source values:

```sql
SELECT id, source_gcs_uri, source_json_url, video_url
FROM records
WHERE LOWER(COALESCE(source_gcs_uri, '')) IN ('unknown', 'none', 'n/a', 'placeholder')
   OR LOWER(COALESCE(source_json_url, '')) IN ('unknown', 'none', 'n/a', 'placeholder')
   OR LOWER(COALESCE(video_url, '')) IN ('unknown', 'none', 'n/a', 'placeholder')
LIMIT 100;
```
